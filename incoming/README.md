# 캐릭터 이미지 넣는 곳

이 폴더에 이미지를 **아래 romanized 파일명**으로 저장한 뒤 (png/jpg/jpeg/webp 가능):

```
node scripts/import-images.mjs incoming
```

를 실행하면 올바른 카드 폴더로 자동 배치되고 placeholder(.svg)는 제거됩니다.
전부 다 넣을 필요 없이, 넣은 것만 반영되고 나머지는 placeholder로 남습니다.
